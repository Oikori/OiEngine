# 永夜幸存者（Survivors）

类《吸血鬼幸存者》的俯视角自动战斗生存游戏，与 SandBox、Platformer 一样是引用 `Engine` 的独立可执行工程。
美术主体是程序化几何（顶点色网格）；`assets/textures/` 里另有 9 张可选的贴图精灵（4 角色 + 5 敌人），
有图就贴图、缺图自动退回几何，所以删掉整个 textures 目录游戏照常能玩。

## 构建与运行

```powershell
$cmake = 'D:\Program Files\JetBrains\CLion 2025.2.1\bin\cmake\win\x64\bin\cmake.exe'
& $cmake --preset mingw-debug
& $cmake --build build/cmake-build-debug --target Survivors
```

产物：`output/Survivors.exe`（与 SandBox / Platformer 共用 `output/libEngine.dll`）。命令行直接运行需要 MinGW 运行时在 PATH 中：

```powershell
$env:PATH = "D:\Program Files\JetBrains\CLion 2025.2.1\bin\mingw\bin;$env:PATH"
.\output\Survivors.exe
```

## 操作

| 输入 | 作用 |
| --- | --- |
| 鼠标点击「开始游戏」 | 从标题界面进入开局选择（标题页**没有**键盘快捷键） |
| 鼠标点击角色 / 武器卡，或 Enter | 开局选择：选一个角色和一把武器，然后点底部的「开始战斗」 |
| 游戏说明 / 操作 | 标题页与暂停菜单里的按钮，打开完整说明面板（ESC 关闭） |
| 设置 / 音量 | 标题页与暂停菜单里的按钮，调主音量 / 背景音乐 / 音效，可静音（ESC 关闭） |
| WASD / 方向键 | 移动（武器自动索敌开火，无需攻击键） |
| 鼠标点击卡片 / 1、2、3 | 升级时三选一（只有属性卡） |
| 鼠标点击「刷新全部三张」/ R | 花金币整组重抽（价格每次递增） |
| 鼠标点击武器卡 / 1、2、3、4 | 每 5 级选武器：新武器解锁或已有武器 +1 级 |
| 鼠标点击「购买」/「整组刷新」· R | 每关通关后的商店：买道具、整组重抽货位（R 与按钮同一条路径）；**离开只能点「离开商店」按钮**（Enter / 空格已取消） |
| ESC | 暂停 / 继续（暂停菜单里可「回到标题」/「退出游戏」，不会立刻退出）；**战斗、升级选卡、商店三个阶段都能暂停，继续时回到暂停前的界面**；选角页 ESC = 回标题。点过 F4 调试面板等 ImGui 窗口后照样生效 |
| 鼠标点击右上角「暂停」 | 和 ESC 等价的鼠标路径（只在战斗中显示） |
| R | **只在面板里 = 整组刷新**（升级卡面板 / 商店）；游戏内不响应——重开一局请点结算面板的「再来一局」。与 ESC 一样走物理轮询，点过面板按钮后照样生效 |
| F4 | 调试面板（FPS、实体数、伤害统计、快速验证按钮） |

> 引擎解绑了窗口的输入法（IME）并加了 `GetAsyncKeyState` 物理按键兜底，中文输入法开启时 WASD / 数字键照样生效；
> 所有面板都优先用鼠标点（按钮足够大），键盘 `1/2/3(/4)` 只是额外路径。

## 规则

- 启动后先进入标题界面（开始游戏 / 退出游戏），不会直接开打。
- **开局先选一个角色和一把武器**：角色是「角色类道具」（品质固定史诗，给初始属性 + 一条**专属特性**，四选一：
  守夜人 · 每点防御 +1% 伤害、生命 ≤50% 时防御与回复翻倍；猎手 · 月刃与回旋镰 +40%、月刃穿透变**弹射**；
  修女 · 圣光环 +50%、受伤后 3 秒内回复与攻速翻倍；术士 · 全部伤害 +40%、雷暴变**范围伤害**且基础间隔 -0.75 秒），
  武器决定起手手段（四选一，1 级起手）。
- 关卡制，共 **10 关**：第 1 关存活 30 秒，之后每关 +5 秒（第 10 关 75 秒），撑完第 10 关即胜利；生命归零则结束。
  **第 10 关的「血月使徒」是最终战：击杀它立刻通关**，不必再等剩余时间（计时只是保底）。
- 过关会清空场上敌人与弹丸，地上的金币自动收进钱包，然后**开商店**；**第 5 / 10 关有「血月使徒」**，进关即登场。
- 怪物数值随关卡递增：**小怪血量每关 +30%、防御每关 +20%（线性）**，**伤害是三次曲线**
  （`1 + (n−1)³/81`，第 10 关约 10 倍第 1 关）；**血月使徒的血量单独一条分段曲线**
  （第 5 关 2 倍、第 10 关 40 倍，5→10 关之间每关 ×1.82；伤害/防御同小怪）；
  **经验与金币固定不变**（小怪都是 1 枚、血月使徒 10 枚）。刷怪节奏与兵种也逐关加强。
- **场地围栏**：玩家只能在约 2200×2200 的方形场地内移动（走到边会被挡住），围栏画在四条边上；
  **敌人可以越过围栏**，所以贴着栏杆走的时候仍然会被围上来。
  **围栏外是阴影区**：场地外被压暗，阴影里的敌人**无敌**（打不到、武器也不会锁它），得等它跨进围栏才吃伤害。
- **击杀直接给经验**，敌人死后掉金币（走近自动吸取，**金币不会消失**，过关 / 通关时全地图的金币自动收进钱包）；金币用于**刷新升级卡 / 刷新商店 / 买道具**。
- 升级给三张**属性卡**（九种：力量、急速、疾行、体魄、暴击、爆伤、回春、铁壁、破甲），
  **没有层数上限**，带品质 **普通 / 高级 / 稀有 / 史诗**（加成 ×1.0 / ×1.6 / ×2.4 / ×3.5，等级越高越容易出高品质；
  卡片上只显示品质名与本次加成 / 累计，**不显示层数与加成倍率**）；
  面板下方「刷新全部三张」（快捷键 **R**）花金币**整组重抽**，价格 = 4 + 3 × 本次已刷新次数。
  **选完卡回到战斗有 1 秒无敌**（`LEVELUP_INVULN_TIME`，角色会闪一下），贴脸的敌人打不到你。
- **武器与「立即回复」已从升级卡池移除**：每 **5 级**从四把武器里选一次（月刃 / 圣光环 / 回旋镰 / 雷暴，
  选没拿过的 = 解锁 1 级，选已有的 = +1 级，最高 5 级；全部满级时这次机会折成金币）。
  **雷暴默认是单体伤害**：每道雷只打落点那一只（**一道必打最近的敌人、一道优先打 Boss，其余随机**）；**术士的雷暴才是范围伤害**
  （落点半径 90 → 145 内全部挨打、逐只掷暴击），并且基础攻击间隔 -0.75 秒。
- **道具**分三种（种类决定能不能重复拿）：
  - 普通类 —— 没有持有上限，可以一直叠（血袋、磨刀石、磁石、铁钉 · 普通 / 铁片、猎魂纹、追星靴、猎手斗篷 · 高级；
    猩红吊坠、秘银指环 · 稀有；流光冠冕 · 史诗）
  - 限制类 —— 每件有持有上限 1~3（普通：铸币者之锤 · 上限 3、迷雾灯 · 上限 3、沙漏、成长之书；
    高级：寒铁护腕、血玫瑰、淬血匕首、贪婪契约；稀有：血月徽记、疾风羽、龙鳞、哀嚎钟、受难者圣痕、破晓之刃、节拍器、星辉残页、断刃、诅咒之环、星屑；
    史诗：不朽之心 / 荆棘之甲 / 贪婪之匣 / 猎月瞳 / 贪欲之链 / 黎明誓约 / 狂战徽记 / 血契 / 商人之瞳，每件上限 1）
  - 角色类 —— 开局选择，固定史诗，不进商店
  **稀有度是每件道具写死的档位**（铁片永远是高级、血袋永远是普通），只决定价格与出货权重，
  效果就是道具自身的固定数值（不再按稀有度放大）。
- **事件**：游戏里会发生八类事件 —— **击杀 / 拾取金币 / 受伤 / 过关 / 暴击命中 / 计时（每 8 秒）/ 花费金币 / 升级**，十四件道具挂在事件上：
  击杀：哀嚎钟（每 12 杀音波）· 血契（每次击杀回血）；
  拾金：铸币者之锤（每 10 枚额外铸币）· 拾荒护符（每 10 枚回血）· 贪欲之链（拾币按面额震伤四周）；
  受伤：受难者圣痕（每 5 次受伤暗焰反击）；过关：黎明誓约（每过一关永久成长）；
  暴击：淬血匕首（每次暴击回血）· 破晓之刃（每 8 次暴击光爆）；
  计时：沙漏（每 8 秒回血）· 节拍器（每 8 秒对最近敌人一击）；
  消费：贪婪契约（每花 50 币回血）· 商人之瞳（每花 50 币永久 +伤害）；
  升级：成长之书（升级回血）· 星辉残页（升级 +固定穿甲）。
  暂停菜单的「事件」一栏显示八类事件的累计次数与阈值进度。
- **商店**：每关通关后开一次，一次摆 4 件道具（不卖角色），价格按稀有度 12 / 22 / 40 / 66 再乘关卡系数
  （**前 5 关每关 +20%，第 6 关起再叠 0.4 × (n−5)²**：n=6~9 的系数 2.6 / 4.0 / 6.2 / 9.2，末两关基本买不起史诗），
  越稀有的越难刷出来；**档位按关卡解锁**：第 3 关起才卖稀有档、第 5 关起才卖史诗档（前两关只有普通 / 高级）。
  「整组刷新」（快捷键 **R**）价 = **(6 + 4 × 本次已刷新次数) × (1 + 0.4 × (n−1))**，
  第一次开商店是原价、之后每过一关更贵一档。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `main.cpp` | `Application` 入口，压入一个 `SurvivorsLayer` |
| `SurvivorsGame.h` | 游戏层的唯一声明：状态机、嵌套数据类型、`SurvivorsLayer` 成员与数据（顶部有文件分工表） |
| `SurvivorsGame.cpp` | 主循环与生命周期：BaseStats、相机、清局 / 回标题、音频、关卡推进、玩家移动、输入 |
| `SurvivorsEnemies.cpp` | 敌人：空间哈希、刷怪节奏、移动与分离、接触伤害、Boss 登场 |
| `SurvivorsWeapons.cpp` | 武器：索敌 + 月刃 / 圣光环 / 回旋镰 / 雷暴的开火与弹丸推进 |
| `SurvivorsCombat.cpp` | 伤害结算、击杀、玩家受伤（荆棘反弹 / 不朽之心复活）、金币掉落与拾取、粒子 / 光环 / 伤害数字 |
| `SurvivorsUpgrade.cpp` | 经验与升级卡：卡池（只剩属性卡）、品质掷点、整组刷新、属性结算 |
| `SurvivorsItems.cpp` | 道具系统：目录 / 持有上限 / 效果、商店（掷货 / 刷新 / 购买）、开局选角与每 5 级选武器、面板排队 |
| `SurvivorsEvents.cpp` | 事件系统：`RaiseEvent`（击杀 / 拾取金币 / 受伤 / 过关 / 暴击 / 计时 / 消费 / 升级）与事件道具的响应（回血 / 铸币 / 范围爆发 / 永久成长） |
| `SurvivorsRender.cpp` | 世界渲染（程序化网格 + 贴图精灵的绘制顺序与变换） |
| `SurvivorsUi.cpp` | 全部 ImGui 面板：标题 / 选角 / HUD / 升级卡 / 选武器 / 商店 / 暂停 / 结算 / 帮助 / 设置 |
| `SurvivorsInternal.h` | 内部共享的调参表、调色板与数学小工具（`inline`，仅本工程使用） |
| `SurvivorsArt.h/.cpp` | 程序化几何库：**四个角色形象**（重甲守夜人 / 弓手 / 修女 / 术士）/ 五种敌人 / 投射物 / 金币 / 特效 / 地面装饰；同时负责加载 `assets/textures/` 里的可选贴图精灵 |
| `assets/audio/` | 2 首 BGM + 11 个音效（程序化生成，无外部素材） |
| `assets/textures/` | 9 张可选精灵（`player_*` 4 张 + `enemy_*` 5 张，512×512 透明 PNG），缺文件自动退回几何剪影 |
| `assets/textures/icons/` | 53 张可选图标（40 道具 + 4 武器 + 9 被动，256×256），升级卡 / 武器卡 / 商店 / 暂停面板都用它 |
| `assets/shader/scenes/survivors_sprite.glsl` | 贴图精灵着色器（position + uv，`u_Tint` 染色 / `u_Flash` 闪白） |
| `tools/generate_audio.py` | 音频生成脚本：`python Survivors/tools/generate_audio.py` |
| `tools/prepare_sprites.py` | 立绘切图脚本：白底图片 → 透明精灵（去背 / 去白边 / 统一画布），支持单图与网格图集 |

实现要点：

- 音频：`LoadAudio()` 在 `OnAttach` 加载全部资源；`EnsureBgm(boss)` 管 BGM（标题页主曲 → Boss 关切曲 → 过关切回，
  阵亡 / 通关停曲再播长音效）；`PlaySfx()` 每槽位独立冷却 + 随机变调，扛住每秒几十次命中 / 拾取。
  F4 面板可静音与调主音量。
- 正交相机跟随玩家，世界单位与像素按 900 高度 1:1 映射；窗口改变宽高比时自动调整横向可视范围。
- 敌人用 **空间哈希**（96 单位网格）做邻近查询：分离、索敌、弹丸碰撞、光环与落雷都是 O(n·k)，
  默认上限 420 个敌人。
- 金币是同构的掉落物 `Coin`：击杀当场结算经验、地上只掉钱；磁吸、拾取提示（金色 `+N`）在 `UpdateCoins()` 里，
  **金币不过期**（过关 / 通关时全地图自动收进钱包），
  实际到手数额统一走 `CoinGain()`（贪婪之匣的金币倍率）。升级卡的品质由 `RollRarity(depth)` 按等级掷权重，
  刷新价由 `RerollCost()` / `ShopRerollCost()` 统一给出（面板与暂停菜单读同一个数）。
- 面板排队：一次击杀可能连升两级、过关时还挂着升级，`ContinueRun()` 统一按 升级 → 选武器 → 商店 的顺序推进。
- 道具只在 `SurvivorsItems.cpp` 里增删：加一个 `ItemId` + 一条 `ITEM_DEFS`（含**固定稀有度**与 `gain[5]` 数值）+ `ApplyItemEffect` /
  `DescribeItem` 各一个 case 即可，商店、背包、暂停面板都会自动带上它。`ITEM_DEFS` 是 `unordered_map`、键就是 `ItemId`，
不再要求「下标与枚举顺序一致」（漏登记会在 `.at()` 处直接抛出来）。
  **事件道具**再加一步：在 `SurvivorsEvents.cpp` 的 `RaiseEvent()` 对应事件分支里读 `BaseStats` 的那组数
  （阈值节奏常量在 `SurvivorsInternal.h`），暂停面板的进度行由 `EventSummary()` 统一生成。
- 敌人跑出 1400 单位后从视野外重新入场，避免玩家直线逃跑时屏幕空无一人；Boss 单独处理。
- 深度测试为 `GL_LESS`，所有绘制按 z 递增排列；屏幕暗角用径向渐变网格，最后绘制以免出现矩形接缝。
- 场景每帧显式声明 `Renderer::SetHDREnabled(false)` / `SetLightCullingEnabled(false)`，避免引擎全局开关残留。
