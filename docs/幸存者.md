# 幸存者（Survivors/）

> 返回 [AGENTS.md](../AGENTS.md)。相关：[平台跳跃](平台跳跃.md)（输入屏蔽约定）、[ImGui 与输入](ImGui与输入.md)（IME 吞键）。

独立可执行工程（根 `CMakeLists.txt` 里的 `add_subdirectory(Survivors)`），不依赖 SandBox；只链接 `Engine`。

- **玩法**：WASD 移动 + 武器自动索敌；击杀敌人**当场获得经验**，掉落物是**金币**；升级三选一，可用金币整组刷新；
  **关卡制，共 10 关**，撑完第 10 关即胜利。四把武器（月刃 / 圣光环 / 回旋镰 / 雷暴）+ 九种属性卡（无层数上限，带品质）+ 补给卡，
  卡池在 `BuildUpgradePool()`、品质与文案在 `RollOption()`
- **经验与金币**：`KillEnemy()` 里 `GainExp(enemy.xp)` 直接结算经验，同时 `SpawnCoin()` 撒下金币（面额见 `ENEMY_TUNING` 的 `coins`，
  按关卡 +10%/关；石魔拆两枚、使徒拆十二枚）。金币**只用于刷新升级卡**，拾取时飘出金色 `+N`；
  掉落物 22 秒（`COIN_LIFETIME`）后过期散掉，掉落表满（`MAX_COINS`）时最老的一枚直接折成钱，不会静默丢失
- **刷新升级卡**：面板下方一个「刷新全部三张」按钮，**整组重抽**（三张一起换，且尽量不重复刚才那三张），不消耗升级次数。
  价格 `RerollCost()` = `4 + 3 × 本次选取已刷新次数`，次数在每次开面板时清零（`StartLevelUp()` / `ApplyUpgrade()`）；
  金币不足时按钮置灰并显示「需 N 币」
- **品质**：属性卡 / 补给卡带品质 `普通 / 高级 / 稀有 / 史诗`，加成倍率 **1.0 / 1.6 / 2.4 / 3.5**，
  抽卡权重随等级倾斜（`RollRarity()`：普通 58−1.4×等级 起，史诗 4+0.55×等级）。武器卡是固定的等级进阶，不带品质
- **属性卡无上限**：`PASSIVE_MAX` 已移除，同一张卡可以一直叠（面板显示「×N」）。为防堆叠打崩玩法只留三条硬上限：
  移速 ≤ 2× 裸值、暴击率 ≤ 100%、百分比穿甲 ≤ 100%（`MOVE_SPEED_CAP_MUL` / `CRIT_CHANCE_CAP`）
- **关卡**：第 `n` 关存活 `30 + 5 * (n - 1)` 秒（第 1 关 30 秒，第 10 关 75 秒，全通约 525 秒）；
  **只有第 5 / 10 关有「血月使徒」**，进关时直接从玩家周围 560 单位处刷新。过关由 `AdvanceStage()` 处理：
  清空剩余敌人与弹丸、地上金币自动收进钱包、重置刷怪计时，并触发 2.2 秒进关横幅（Boss 关显示血色横幅 + 一层血光）。
  怪物数值按关卡递增（`SpawnEnemy()`）：血量 +30%/关、伤害 +12%/关、防御 +8%/关、经验与金币 +10%/关；
  刷怪间隔与同屏波数也随关卡收紧，兵种逐关放开（第 2 关起有食尸鬼、第 4 关起怨灵、第 7 关起石魔）
- **入口**：启动先进 `State::Title`（标题面板：开始游戏 / 游戏说明 / 退出游戏，Enter/空格 或点击开始），`ResetRun()` 负责开一局；
  `OnAttach` 里 `ResetRun()` 后切 Title 并清掉开局敌人，标题画面不跑游戏逻辑、也不显示 HUD
- **帮助面板**：标题页与暂停菜单里都有「游戏说明 / 操作」按钮，`m_showHelp` 驱动 `RenderHelp()`（最后绘制，永远在最上层），
  内容是关卡规则 / 操作 / 成长 / 属性与品质 / 敌人五段；ESC 或面板内的关闭按钮收起。帮助打开时输入被接管：
  ESC 只关帮助，不会顺手开始游戏、暂停或重开（`OnEvent` 与暂停菜单的 ESC/P 兜底都做了守卫）
- **属性**：`BaseStats` 是一局内唯一的属性数据（开局为裸值 `BARE_STATS`，初始生命 20），属性卡**直接累加**到对应字段，
  战斗、升级卡描述、暂停面板都只读它；`RecalculateStats()` 只做「同步生命上限 + 钳制当前血量」，不做任何乘算。
  单张卡的步长 = 基准 × 品质倍率（`PassiveGainFor()`，描述与结算共用同一份算式）；百分比型成长（移速 7% / 拾取 35%）
  按开局裸值取比例，叠加是线性加成而非复利
- **防御 / 穿甲**：**防御只有固定值**，减伤率 = `防御 / (防御 + 100)`（100 点 = 50%，只会趋近 100%，
  所以没有减伤保底）。穿甲分两档，都作用在对方的防御值上：百分比穿甲先按比例削、固定穿甲再扣点（扣到 0 为止），
  剩下的防御再按上式换减伤率。结算统一走 `ResolveDamage()`（攻防两端共用），等价写法：
  `raw * 100 / (100 + max(0, 防御 * (1 - 穿甲%) - 固定穿甲))`。
  玩家靠「铁壁」（每张 +8 防御起，可无限叠）/「破甲」（每张 +4 固定穿甲 · +8% 百分比穿甲起）成长；
  **怪物只有防御、没有穿甲**（`ENEMY_TUNING` 的 `defense`：蝙蝠 0 / 食尸鬼 5 / 怨灵 12 / 石魔 25 / 使徒 40），
  所以玩家的防御在挨打时全额生效，玩家的穿甲按上述顺序抵消怪物防御
- **音频**：`Survivors/assets/audio/`（`Survivors/tools/generate_audio.py` 程序化生成）——
  2 首 BGM（主曲 / Boss 曲，streaming 循环，标题页起主曲、进 Boss 关切曲、过关切回）+ 11 个音效。
  `EnsureBgm(boss)` 管 BGM 生命周期（同一首只 Resume，换曲才停旧起新），`PlaySfx(SfxId, ...)` 按槽位冷却（45~120 ms）
  并按事件变调，避免命中 / 拾取连成一片；阵亡与通关会停 BGM 再播长音效。详见 [音频](音频.md)
- **音量 / 设置**：三级音量——主音量走 `AudioEngine::SetMasterVolume`，背景音乐与音效是应用层系数
  （引擎没有音频总线）：BGM 在 `EnsureBgm` / `ApplyBgmVolume` 里乘进场声部音量，音效在 `PlaySfx` 里乘进每次播放。
  标题页与暂停菜单都有「设置 / 音量」按钮打开 `RenderOptions()`（三条滑条 + 静音，ESC 关闭），
  设置只在本次运行内有效，不落盘
- **输入**：移动用 `Input::IsKeyPressed` 轮询；升级卡必须能用**鼠标点击**，键盘选择只是额外路径。
  中文输入法不会吞按键：引擎解绑了窗口的 IME，并有物理按键（GetAsyncKeyState）兜底（见 [ImGui 与输入](ImGui与输入.md) 的「输入法」一节）
- **ESC**：不直接退出，打开暂停菜单（继续游戏 / 重新开始 / 退出游戏），`P` 等价。
  暂停菜单打开后是交互窗口，游戏层收不到键盘事件，所以额外用 `ImGui::IsKeyPressed(..., false)` 补了一条 ESC/P 继续；
  只用「按下那一帧」（`repeat = false`），并且开菜单后有 **0.25 秒**宽限（`m_pauseGuardTime`）——
  系统消息可能比物理按键状态晚到几帧，宽限太短会让同一个 ESC 把刚打开的菜单又关掉（菜单一闪而过）
- **结算窗口**：阵亡与通关面板都提供「再来一局 (R) / 回到标题 / 退出游戏」，并展示击杀 / 等级 / 获得金币 / 伤害。
  `ReturnToTitle()` = `ResetRun()`（重置关卡、属性、金币、音频并刷开局敌人）后切 `State::Title`，
  再清空敌人 / 弹丸 / 金币 / 粒子 / 伤害数字 / 空间哈希，所以标题画面不会有残留敌人，下一局也一定从第 1 关开始
- **敌人管理**：敌人数量上限 420；用 `EnemyGrid`（96 单位空间哈希）做分离 / 索敌 / 弹丸碰撞 / 光环查询；
  敌人离玩家超过 1400 单位会从视野外重新入场（Boss 单独按 1100 单位处理），否则玩家直线逃跑会让屏幕空掉
- **渲染**：全部程序化顶点色网格（`SurvivorsArt`），单 shader（`u_Transform` / `u_Tint` / `u_Falloff`）；
  正交相机跟随，900 高度基准 1:1。深度测试是 `GL_LESS`，**屏幕暗角（径向渐变网格）必须最后画**，
  否则它会写入深度、把 z 更小的全屏闪光裁成一个椭圆。HUD 只保留左上「生命 / 等级 / 金币」、顶部中央「关卡计时 + 击杀」、
  以及按需出现的 Boss 血条与进关横幅；武器与属性清单只在暂停面板里查看
- **每帧**显式 `Renderer::SetHDREnabled(false)` / `SetLightCullingEnabled(false)`，与 SandBox 各场景同样的约定
- 调试：F4 面板；`output/Survivors.exe` 直接运行同样需要 MinGW 运行时 DLL 在 PATH 中

## 代码分工

游戏层只有一个类 `SurvivorsLayer`，但按职责拆成多个 `.cpp`（都只定义它的成员函数，共享 `SurvivorsGame.h`；
新增 `.cpp` 要同时加进 `Survivors/CMakeLists.txt`）：

| 文件 | 职责 |
|---|---|
| `SurvivorsGame.cpp` | 主循环与生命周期：`BaseStats` 定义、相机、开局 / 重开 / 回标题、音频、关卡推进、玩家移动、输入事件 |
| `SurvivorsEnemies.cpp` | `EnemyGrid` 空间哈希、刷怪节奏、敌人移动与分离、接触伤害、Boss 登场 |
| `SurvivorsWeapons.cpp` | 索敌 + 四把武器的开火 / 冷却（`UpdateWeapons`）与弹丸推进（`UpdateProjectiles`） |
| `SurvivorsCombat.cpp` | `DamageEnemy` / `KillEnemy` / `DamagePlayer`、金币掉落与拾取、粒子 / 光环 / 伤害数字及更新 |
| `SurvivorsUpgrade.cpp` | `GainExp`、卡池与品质（`BuildUpgradePool` / `RollOption`）、整组刷新、`ApplyUpgrade` |
| `SurvivorsRender.cpp` | `RenderWorld` 与全部 `Draw*`（程序化网格绘制顺序） |
| `SurvivorsUi.cpp` | `OnImGuiRender` 与全部面板（标题 / 帮助 / 设置 / HUD / 升级卡 / 暂停 / 阵亡 / 通关） |
| `SurvivorsInternal.h` | **内部**共享：尺寸与节奏常量、调色板、武器 / 敌人数值表、品质表、`ResolveDamage` 等 `inline` 工具 |

`SurvivorsInternal.h` 里的东西全部是 `inline` / `inline constexpr`（拆文件后需要跨翻译单元共用同一份定义），
只在 Survivors 目标内部 include；改数值只动这一个文件，逻辑各回各文件。
