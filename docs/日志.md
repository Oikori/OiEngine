# 日志

> 返回 [AGENTS.md](../AGENTS.md)。相关：[代码约定](../AGENTS.md#代码约定)。

- `OI_TRACE/OI_INFO/OI_WARN/OI_ERROR/OI_CRITICAL` 在 `Engine/Engine/Core/Log.{h,cpp}`，后端是 spdlog：
  `Logger::Init()`（由 `Application::Init()` 调用）建两个 logger——彩色控制台 `console` 与轮转文件
  `logs/OiEngine.txt`（单文件 5 MB、保留 3 份；相对工作目录，即从 `output/` 启动时落在 `output/logs/`）
- 宏用 `std::format` 格式化（支持 `{0}` 位置参数与普通 `{}`），再把 `__FILE__` / `__LINE__` 作为
  `spdlog::source_loc` 传给 logger；文件日志的 pattern 带 `[file:line]`，控制台用 spdlog 默认 pattern
- 级别：logger 默认 `info`，所以 `OI_TRACE` 默认不输出；`Logger::SetLevel(LogLevel)` 把级别同时设到两个 logger
- 格式串必须是编译期字面量（`std::format` 的 consteval 检查）；`glGetString()` 之类的 `const GLubyte*` 要先
  `reinterpret_cast<const char*>`
- OpenGL 调试输出（`OI_DEBUG` 构建）会经 `glDebugMessageCallback` 送到日志——MEDIUM/HIGH 级别的 GL 错误会直接打在控制台
