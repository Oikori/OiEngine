# 室内多光源场景渲染 · 修改方案

> 状态：已确认取舍，实施中（阶段 A / B 先行，阶段 C 随后）。
> 相关代码：`Engine/Engine/Renderer/`、`Engine/Platform/OpenGL/`、`SandBox/ShadowDemo.cpp`（现有 PBR 光照）。

## 一、目标与已确认的取舍

室内多光源场景与当前实现（单光照 UBO、32 光源上限、`(1-d/range)²` 衰减、仅方向光阴影、逐物体 tonemap）存在根本冲突。已确认的技术决策：

| 决策项 | 结论 |
|---|---|
| 光源规模 | **100+ 动态光源** → 阶段 A（SSBO，上限 256）+ 阶段 B（Forward+ clustered 剔除） |
| 衰减模型 | **直接物理化**：windowed inverse-square（`(saturate(1-(d/range)^4))² / d²`），旧场景同步调参，不做兼容开关 |
| HDR / tonemap | **现在就引入**：RGBA16F 离屏目标 + 全屏 tonemap pass，曝光全局统一（为 bloom / 体积光留口） |
| 阴影范围 | **只做方向光 + 聚光灯**（方向光沿用单张 2D 深度图；聚光灯用深度纹理数组，每盏一层）。点光源不做 cube/双抛物面 |
| IBL | **真探针**：程序化捕获室内 cubemap → irradiance 卷积 + prefilter mip + BRDF LUT（不依赖外部 HDR 资产） |

管线形态保持 forward（不做 deferred / light prepass）：场景着色器仍是各场景自持，沿用 `Renderer::Submit` + `BeginScene/EndScene` 的写法。

## 二、现状与差距

| 能力 | 现状 | 室内需求 |
|---|---|---|
| 光源数量 | 光照 UBO 固定 `MaxLights = 32`（`Renderer.cpp`），片元全遍历 | 100+ 光源，需剔除 |
| 衰减 | `clamp(1 - d/range)^2`，强度与 range 无关 | 物理 1/d² + 窗函数截断 |
| 阴影 | 仅方向光 1 张深度图，`ComputeVisibility` 写死单个 `u_LightSpaceMatrix` | 方向光 + 聚光灯（每盏一层） |
| 曝光 / tonemap | 每个 lit shader 各自 ACES + gamma | 全局 tonemap（HDR 缓冲） |
| 间接光 | 常量 `ambient * AO` | 室内探针（IBL） |
| 缓冲格式 | `RGBA8` / `RED_INTEGER` / `DEPTH24(STENCIL8)` | HDR：`RGBA16F` |

可行性：glad 已加载 GL 4.6（含 `glDispatchCompute` / `glBindBufferBase`），SandBox 着色器已是 `#version 450 core`，无需更换渲染后端。

## 三、阶段 A：管线打底

### A1 光源数据迁到 SSBO（binding = 3）

- 新增 `Engine/Engine/Renderer/StorageBuffer.h` + `Engine/Platform/OpenGL/OpenGLStorageBuffer.{h,cpp}`（照 `UniformBuffer` 的写法，`GL_SHADER_STORAGE_BUFFER`）。
- 光照块改为 std430 SSBO，`MAX_LIGHTS = 256`：

  ```glsl
  layout(std430, binding = 3) buffer Lighting {
      vec4  u_Ambient;       // rgb: 颜色；a: 强度
      ivec4 u_Counts;        // x: 光源数；y: 阴影矩阵数；z: 每 cluster 光源上限；w: 备用
      vec4  u_ClipPlanes;    // xyz: near / far / 1/log(far/near)（cluster 深度切片用）
      ivec4 u_Grid;          // x/y: tilesX / tilesY；z: 深度切片数；w: 是否启用 cluster 剔除
      Light u_Lights[MAX_LIGHTS];
      mat4  u_ShadowMatrices[MAX_SHADOW_CASTERS];
  };
  ```

- `LightData` 扩为 5×vec4 = 80B：`flags` 存放 `shadowIndex`（-1 不投影）与逐光源 `shadowBias`。
- C++ 侧 `static_assert` 校验 offsetof / sizeof；上传前做一次相机视锥剔除（可选）。

### A2 物理衰减

```glsl
float w = clamp(1.0 - pow(distance / range, 4.0), 0.0, 1.0);
float attenuation = (w * w) / max(distance * distance, 0.01);
```

`intensity` 语义变为"1m 处照度"，典型值 20~200；聚光锥形因子乘在衰减之上。旧场景（太阳系）同步调参。

### A3 HDR 离屏 + 全局 tonemap

- `FramebufferTextureFormat` 增加 `RGBA16F`。
- 新增 `Engine/Engine/Renderer/PostProcess.{h,cpp}`：HDR 目标 + 全屏三角形（`gl_VertexID`，无需 VBO）+ `TonemapPass`（ACES + gamma + 曝光），预留 chain 形态供 bloom 接入。
- `Renderer`：`SetHDREnabled(bool)` / `SetExposure(float)`；开启时 `BeginScene` 绑定 HDR 目标并清屏，`EndScene` 解绑并跑后处理输出到默认帧缓冲（场景层代码不需要改，ImGui 仍在之后绘制）。
- 新场景着色器输出线性 HDR（不做 tonemap / gamma）；**旧场景默认不开 HDR**，行为不变。

### A4 多光源阴影（方向光 + 聚光灯）

- 方向光：沿用现有 `ShadowMap`（2D）+ `Shadow` UBO（binding = 2）。
- 聚光灯：新增 `Engine/Engine/Renderer/ShadowMapArray.{h,cpp}`（深度纹理数组，每盏一层，NEAREST + CLAMP_TO_BORDER 与现有约定一致）。
  - 新增 `ComputeSpotLightShadow(light, nearPlane)`（透视投影，fov = 2 × outerAngle）。
  - `SpotLight::shadowIndex` 指向 `Renderer::SetLightShadowMatrix(index, lightSpace)` 登记的光空间矩阵；片元按 `shadowIndex` 采样数组层（3×3 PCF，bias 逐光源）。
- 预算：投影光源 ≤ 8 盏（`MAX_SHADOW_CASTERS`），阴影 pass 需配合 caster 视锥剔除。

## 四、阶段 B：Forward+ 光源剔除

- 网格：屏幕 16×16 px tile × 24 层视空间深度切片（指数分布）。
- 新增 `Engine/Engine/Renderer/LightClustering.{h,cpp}`：
  - SSBO binding 4：每 cluster 光源计数（`uint[]`）；SSBO binding 5：光源索引列表（`uint[]`，每 cluster 上限 64）。
  - compute pass 1：清空计数；pass 2：逐 cluster 与光源球求交（视空间 AABB vs 球），原子计数写入索引。
  - 网格随窗口尺寸重建；`SetEnabled` 可关闭剔除（回退到全遍历，用于对照排查）。
- `Shader` 扩展：`Shader::CreateCompute(name, src)` + `Dispatch(x,y,z)` + `MemoryBarrier()`（`OpenGLShader` 增加 compute 分支）。
- 片元侧：由 `gl_FragCoord` 与视空间深度算 cluster index，遍历该 cluster 的光源列表；光源结构与阶段 A 的 SSBO 复用。
- 相机 near/far：`Camera` 增加带默认实现的 `GetNearClip()` / `GetFarClip()`，供深度切片使用。

## 五、阶段 C：室内观感

1. **emissive + bloom**（优先）：材质增加自发光（HDR 值域），后处理链加阈值提取 + 多级模糊 + 叠加。
2. **IBL 真探针**：程序化捕获室内 cubemap（把房间几何渲染进 cubemap）→ irradiance 卷积 + prefilter mip + BRDF LUT 预计算；着色器在环境项使用探针（漫反射用 irradiance，镜面用 prefilter + LUT）。
3. **SSAO / 接触阴影**（可选）：需要 MRT（深度 + 法线）。
4. **体积光 + 雾**（可选，stretch goal）。

## 六、落地场景：`SandBox/IndoorDemo`

- 程序化房间（地板 / 四墙 / 天花板 + 桌、柱、书架），复用 PBR 思路、走新光照路径。
- 光源：吊灯、壁灯、台灯、射灯（含聚光灯阴影），可一键加压到 200+ 点光源。

- `main.cpp` 的 `SceneSwitcherLayer` 增加 F6 切换；F4 保持"场景内调试面板"约定。

## 八、验证与风险

- 每阶段收口：全量构建（`cmake --build build/cmake-build-debug`）+ SandBox 四场景 + IndoorDemo 运行观察；布局用 `static_assert`。
- 风险：① 衰减语义变更影响旧场景数值 → 同步调参；② 阴影 pass 随投影光源线性增长 → 上限 8 盏 + caster 剔除；③ cluster 漏光 → 光源求交保守化 + 可关闭剔除对照；④ GL 版本 → 未显式请求 4.5 core（当前靠驱动默认给最高版本），建议后续补 hint。
- 回退：HDR 关闭 = 旧行为；剔除关闭 = 全遍历。

### 与原始方案的差异（实现时的调整）

1. **聚光灯阴影矩阵放在光照 SSBO 里**（`u_ShadowMatrices[MAX_SHADOW_CASTERS]`），而不是扩 Shadow UBO ——
   矩阵与光源数据同源，只上传一次；方向光仍然走原来的 Shadow UBO，两条路径互不干扰。
2. **IBL 镜面项仍用 Karis 解析 env BRDF 近似**，没有单独预计算 BRDF LUT（少一张纹理与一个 pass，视觉差异很小）；
   irradiance / prefilter 都是真探针。
3. **捕获用的材质是简化着色**（albedo × (常量环境光 + 阳光) + 自发光），不是完整光照 pass ——
   探针不能引用自身，这是一次弹射的近似；面板上的 "Probe sun scale" 用来避免直射阳光被重复计算。
4. `LightClustering::MaxLightsPerCluster = 48`：室内尺度（光源 range 1~2.5 m）下溢出为 0；
   大 range 光源（≥3.5 m）在 200 盏时会把列表撑爆（实测溢出 5.8 万个 cluster），
   解决方向是缩小光源 range，而不是盲目加大上限（每 cluster 上限直接决定索引 SSBO 显存）。
5. 顺带修复/改进：`Log.h` 的日志宏此前是空实现（GL 错误被静默吞掉），改为 `std::format` 版实装；
   `OpenGLRendererAPI::Init` 里 `HZ_DEBUG` → `OI_DEBUG` 的拼写 bug 修复（GL 调试回调现在真的会开）。
6. 相机增加了 `GetNearClip()/GetFarClip()`（cluster 深度切片需要），室内相机把机位 `glm::clamp` 在房间内。

### 后续可选增强

- bloom（`PostProcess` 链加"阈值 + 多级模糊 + 叠加"），让灯具 / 窗户带辉光
- 点光源阴影（cube map 或双抛物面，每盏 6 次 / 2 次 pass）
- SSAO / 接触阴影（需要 MRT：深度 + 法线）、体积光（窗户光柱、聚光灯雾）
